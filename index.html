Medarbejderstatistik – denne måned

Cloud-lagring

Første gang: opret databasetabellen med den medfølgende SQL-fil i Supabase. Når cloud er tom, kan du overføre de nuværende lokale data.

POS styrer pakketal fra den dag, denne version tages i brug. Tidligere måneder ændres ikke automatisk. Tomme månedstotaler uden registreringer ryddes automatisk, så dagstal kan bruges. Månedstotaler med data bliver aldrig slettet eller overskrevet automatisk.

Backup

Cloud-backup er aktiv, når status viser Synkroniseret. Eksportér fortsat backup regelmæssigt.
